## About this site

**Screeps Combat Lab** is a technical blog about building and improving combat systems for [Screeps](https://screeps.com/), the programming-focused multiplayer strategy game.

The goal is to publish two kinds of work:

- **Guides and bot design:** explain reusable ideas, system boundaries, implementation choices, and practical programming patterns.
- **Research and battle reports:** document experiments, compare approaches, analyse observed behaviour, and record lessons from both successes and failures.

## How to read the articles

Code snippets are intended as educational examples, not drop-in modules. Screeps APIs, game balance, and bot architecture can change, so each article should identify the environment and assumptions behind its examples.
